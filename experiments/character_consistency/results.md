# 인물 일관성 실험 결과 (E2)

- **담당**: 김민진 (E2)
- **목적**: 같은 인물이 여러 장면에서 같은 사람으로 보이게 하는 생성 방식 고르기 (E2 계획서 3.3)
- **스크립트**: `run_experiment.py`(생성) → `make_eval.py`(블라인드 평가지) → `score.py`(집계)
- **테스트 꿈**: `test_dream.json` — 인물 2명(할머니, 남동생)이 장면 5개 중 4개씩 등장

## 조건

| 조건 | 생성 방식 |
| --- | --- |
| A 기준 | 인물 이름·관계만 프롬프트에 넣음 ("the grandmother") |
| B 특징 주입 | A + 머리 모양·머리색·옷차림·나이대·구별되는 특징 고정 문구를 모든 장면에 반복 |
| C 특징+고정 | B + 공통 화풍·구도 고정 (`worker/image_gen/prompt.py`의 `build_prompt`, 서비스 기본 방식) |
| D 참고 이미지 | C + 1장면 이미지를 참고 이미지로 넣어 2~5장면 생성 (`images.edit`) |

- 계획서의 C 조건에는 **시드 고정**이 있지만 OpenAI 이미지 API는 seed를 지원하지 않아 화풍·구도 고정만 적용했습니다.
- 모델·크기·품질: `gpt-image-2`, `1536x1024`, `medium` (조건 모두 같음)

## 평가 방법

- 같은 인물이 나오는 두 장면(처음 나온 장면 vs 이후 장면)을 짝지어 조건을 숨기고 순서·좌우를 섞어 보여 줌
- 평가자는 "두 그림의 인물이 같은 사람으로 보이는가"를 1~5점으로 답함
- **4점 이상 = 같은 인물로 인식** (DB 지표 뷰 `v_character_consistency`와 같은 기준)
- 조건당 6쌍(인물 2명 × 3쌍), 전체 24쌍
- 이 실험의 인물은 모두 확신도 "확실"로 가정. 흐릿한 인물은 블러로 일부러 흐리게 표현되므로 따로 집계함 (계획서 3.3)

### 생성 직후 관찰 (평가 전, 담당자 의견)

- A: 장면마다 인물이 달라짐. 5장면의 할머니는 인종·옷차림이 다르고, 남동생 옷도 장면마다 바뀜
- B: 분홍 카디건, 흰 단발, 노란 우비 등 지정한 특징이 모든 장면에 유지됨. 실사풍
- C: B와 비슷하게 유지되고 화풍이 통일됨(그림풍)
- D: C와 비슷하고 장면 간 색감·얼굴 인상이 가장 비슷해 보임
- 블라인드 평가 결과로 확정할 것
