# 꿈 세계관 화면 (연결과 확장)

여러 꿈에 반복해 나온 인물과 장소를 지도로 이어 보고, 세계관 항목을 등록하거나 외형을 고치는 화면입니다. 주소는 `/world`이고, 기록 화면과 결과 화면 왼쪽 메뉴의 **꿈 세계관**으로 들어옵니다.

## 화면 구성

| 영역 | 내용 |
| --- | --- |
| 세계관 지도 | 원 하나가 세계관 항목 하나입니다. 가장 많이 나온 항목이 가운데, 원이 클수록 자주 나온 항목입니다. 같은 꿈에 함께 나온 항목은 선으로 잇고, 함께 나온 꿈이 많을수록 선이 굵습니다. 전체, 인물, 장소로 걸러 볼 수 있습니다. |
| 오른쪽 상세 | 고른 항목의 등록 외형, 함께 나온 항목, 이 항목이 나온 꿈 목록(날짜, 장면 순서, 꿈 제목)입니다. 꿈을 누르면 그 꿈의 스토리보드(`/?dreamId=`)로 갑니다. 연필 버튼으로 외형을 고칩니다. |
| 자주 나온 인물, 자주 나온 장소 | 많이 나온 순서로 4개씩 보여 줍니다. |
| 꿈 경로 보기 | 상세의 꿈 목록에서 "지도에서 경로 보기"를 누르면, 그 꿈에서 장면 순서대로 지나간 항목을 번호와 화살표로 지도에 보여 줍니다. 장면마다 장소를 먼저, 장소가 없으면 인물을 씁니다. |
| 기간 | 오른쪽 위에서 전체 기간, 최근 30일, 최근 90일을 고르면 그 기간에 기록한 꿈만으로 횟수와 연결선을 다시 셉니다. |
| 세계관에 추가할 수 있는 이름 | 꿈에 나왔지만 아직 등록하지 않은 인물과 장소입니다. 누르면 이름과 종류가 채워진 등록 화면이 열립니다. |

다른 화면에서 `/world?entity=<항목 id>`로 들어오면 그 항목이 골라진 상태로 열립니다. 항목을 고를 때마다 주소의 `entity`도 바뀌어서 새로고침해도 유지됩니다.

이름을 바꾸면 예전 이름으로 나왔지만 아직 서버에서 연결되지 않은 꿈은 그 항목에서 빠지므로, 수정 화면에서 미리 안내합니다.

## 사용 API

| API | 용도 |
| --- | --- |
| `GET /world/entities` | 세계관 항목 목록 |
| `POST /world/entities` | 항목 등록 (빈 칸은 보내지 않음) |
| `PATCH /world/entities/{id}` | 이름과 외형 수정 (빈 칸은 빈 문자열로 보내 지움) |
| `GET /dreams` | 꿈 목록. 상태가 `scenes_ready`, `images_ready`, `rendered`인 꿈만 아래 장면 목록을 부릅니다. |
| `GET /dreams/{id}/scenes` | 장면 순서, 장면 이미지, 요소별 `entity_id` |

장면 목록은 꿈마다 한 번씩 부르며 동시에 4개까지만 요청합니다. `GET /dreams/{id}/elements`는 첫 조회 때 LLM 재추출이 일어날 수 있어서 쓰지 않습니다.

## 연결 규칙

- 요소에 `entity_id`가 있으면 그 항목에 나온 것으로 셉니다.
- `entity_id`가 없으면 서버 `link_dream_elements_to_world`와 같은 규칙(같은 종류, 앞뒤 공백과 대소문자를 무시한 같은 이름)으로 찾아 함께 셉니다. 서버는 장면을 만들 때만 연결하므로, 나중에 등록한 항목도 지난 꿈에서 바로 보이게 하려는 것입니다. 이런 꿈은 상세에 "이름이 같아서 찾은 꿈"으로 따로 안내합니다.
- 다른 항목에 이미 연결된 요소는 이름이 같아도 옮기지 않습니다.
- 항목 그림은 그 항목이 나온 가장 최근 꿈의 장면 이미지이고, 없으면 이름 첫 글자를 보여 줍니다.

등록한 외형(나이대, 머리, 옷차림, 특징)은 E2 이미지 생성 문장에 그대로 들어가므로, 화면에서 영어로 적기를 권합니다.

## 실행

다른 화면과 같이 `frontend/.env.local`에 `NEXT_PUBLIC_API_BASE_URL`을 넣으면 서버 조회 모드, 없으면 예시 모드입니다. 예시 모드는 `example-world.ts`의 가상 데이터를 쓰고, 등록과 수정은 새로고침하면 사라집니다.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `DreamWorld.tsx` | 화면 틀, 불러오기, 등록과 수정 저장 |
| `WorldMap.tsx` | 지도, 연결선, 확대와 축소 |
| `EntityPanel.tsx` | 오른쪽 상세(`EntityDetail`)와 등록, 수정 입력(`EntityForm`) |
| `NodeMedia.tsx` | 항목 그림 또는 첫 글자 |
| `world-api.ts` | API 호출, 응답 변환, 지도 데이터 만들기(`buildWorld`) |
| `layout.ts` | 지도 위 원의 자리 계산 |
| `example-world.ts` | 예시 모드 데이터 |
| `types.ts`, `Icon.tsx`, `dream-world.module.css` | 형식, 아이콘, 스타일 |

화면 틀, 색, 화면 너비 기준은 B2 결과 화면과 같은 값을 씁니다. 테스트는 `tests/world.test.mjs`입니다.
