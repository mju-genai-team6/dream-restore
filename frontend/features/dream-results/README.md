# B2 결과 및 보관 화면

발표 PDF 4~6쪽의 왼쪽 메뉴, 가운데 콘텐츠, 오른쪽 상세 영역을 참고한 화면입니다.

## 구현한 화면

- 스토리보드: 장면 선택, 설명 및 요소별 확신도, 내용 수정, 수정본 보관, 이전 버전 조회
- 꿈 보관함: 제목 검색, 꿈 기록 상세, 선택한 꿈의 스토리보드 재열람
- 영상 결과: 결과가 없을 때의 안내, 결과 URL이 있는 경우 실제 영상 재생, 수정 전 영상 구분

예시 모드의 내용 수정은 제목, 장소, 설명 및 기존 요소의 확신도를 직접 고치는 기능입니다. 자연어 명령을 AI가 해석하거나 이미지를 재생성하는 기능은 포함하지 않습니다.

## 실행

`frontend` 폴더에서 `npm.cmd run dev`를 실행하고 `http://localhost:3000`을 엽니다.

## 파일 구성

| 파일 | 담당 |
| --- | --- |
| `DreamResults.tsx` | 공통 메뉴, 화면 전환, 현재 꿈 선택 |
| `StoryboardPanel.tsx` | 장면 목록과 상세, 수정 입력, 버전 조회 |
| `ArchivePanel.tsx` | 꿈 보관함 검색, 목록과 상세 |
| `VideoPanel.tsx` | 영상 결과 및 미완료 안내 |
| `SceneArtwork.tsx` | 외부 파일이 필요 없는 예시 벡터 이미지 |
| `Icon.tsx` | 화면에서 사용하는 공통 아이콘 |
| `example-dreams.ts` | 가상의 꿈 2개와 예시 장면 |
| `types.ts` | 화면 데이터 형식, 날짜 및 확신도 표시 |
| `store.ts` | 예시 수정본의 브라우저 저장과 복원 |
| `dream-results.module.css` | 전체 배치와 반응형 스타일 |

## 저장과 서버 연동

이 브라우저의 예시 수정본만 `dream-restore:b2-results:v1` 키에 보관합니다. 실제 DB 저장, 다른 기기 간 동기화, 서버 API 호출은 아직 연결하지 않았습니다. 브라우저 저장이 실패하면 화면에 안내합니다. 최초 기록은 유지하고 장면 수정 시 버전을 추가합니다.

영상 데이터는 `Dream.video`의 URL과 장면별 버전으로 받도록 분리했습니다. 예시에는 완성 영상이 없으므로 영상 결과 화면에서 완료 상태를 표시하거나 임의로 영상을 생성하지 않습니다.

API 연결 시 `docs/rules/`의 상태값, 오류 형식 및 파일 주소 규칙에 맞춰 `example-dreams.ts`와 브라우저 저장 부분을 실제 조회 및 수정 요청으로 대체합니다. DB 버전 관리는 C가 제공하는 계약과 연결합니다.

## 제외한 기능

세계관 지도, 패턴 리포트, 녹음 및 인터뷰, 인물 등록, 장면 추가, 가짜 AI 수정 대화는 포함하지 않습니다.
